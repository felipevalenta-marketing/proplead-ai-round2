# Four-week pilot timeline

| Week | Focus | Output |
|---|---|---|
| 1 | Discovery, data fields and privacy review | Approved workflow, lead schema and success criteria |
| 2 | Build the n8n POC and matching logic | End-to-end workflow using synthetic data |
| 3 | Test multilingual cases and refine prompts | Evaluation results and corrected failure cases |
| 4 | Team training and controlled pilot launch | Human-reviewed pilot with monitoring dashboard |

## Pilot decision gate

Proceed to deployment only if the workflow meets the agreed pass thresholds, agents can understand the scoring logic and the agency approves the GDPR controls.
